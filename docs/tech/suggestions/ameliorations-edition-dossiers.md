# Propositions techniques pour l'édition des dossiers

Les idées de ce document sont des pistes de discussion, pas des fonctionnalités disponibles ni des décisions validées.

## Pistes à réexaminer

- Simplifier la navigation dans les formulaires longs.
- Améliorer le retour à l'utilisateur sur les erreurs et validations.
- Évaluer les besoins de prévisualisation, d'assistance à la saisie ou de sauvegarde intermédiaire.
- Auditer l'accessibilité et mesurer les éventuels coûts de chargement des sections.
- Examiner les besoins de journalisation ou d'export avant d'ajouter un nouveau mécanisme de persistance.

Avant toute mise en œuvre, vérifier le code et la stack actuelle, clarifier le besoin et les règles fonctionnelles, puis évaluer les contraintes de déploiement. Les anciens exemples de code et priorités ont été retirés car ils reposaient sur une stack antérieure et ne décrivaient pas une solution approuvée.
