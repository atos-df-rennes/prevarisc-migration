## ✅ Tests fonctionnels - Affichage des dossiers

### Objectif
Valider automatiquement que l'affichage Symfony est 100% conforme au legacy pour tous les champs et toutes les natures de dossiers.

### Problèmes résolus

#### 1. Installation de Git
**Problème** : Erreur 500 "sh: 1: git: not found" lors de l'exécution des tests  
**Cause** : Le Web Profiler de Symfony nécessite git pour afficher certaines informations  
**Solution** : Installation de git dans le conteneur Docker

```bash
docker exec -u root prevarisc-infra-app-1 bash -c "apt-get update && apt-get install -y git"
```

#### 2. Authentification dans les tests
**Problème** : Redirection vers la page de login  
**Cause** : Le système utilise un `LegacySessionAuthenticator` qui vérifie `$_SESSION['Zend_Auth']`  
**Solution** : Simulation de la session Zend avec le compte root/root

```php
$_SESSION['Zend_Auth'] = [
    'storage' => [
        'USERNAME_UTILISATEUR' => 'root'
    ]
];
```

#### 3. Kernel reboot warnings
**Problème** : Warnings de dépréciation sur le reboot du kernel  
**Solution** : Appel de `ensureKernelShutdown()` avant la création d'un nouveau client

#### 4. Structure HTML des tests
**Problème** : Les tests cherchaient des IDs `#field-{property}` inexistants  
**Cause** : Le template utilise une structure Bootstrap sans IDs spécifiques  
**Solution** : Adaptation des sélecteurs pour analyser la structure réelle :
- Recherche par label dans les `div.libelle`
- Navigation dans les `li.row` pour trouver les valeurs correspondantes

### 🐛 Bug détecté dans le template

**Fichier** : `templates/dossier/index.html.twig` ligne 410

**Avant** :
```twig
{% if dossier|should_display_field('dateVisite') and dossier.dateReunion %}
    <li class="row">
        <div class="left libelle col-md-3">Date réunion</div>
        ...
```

**Après** :
```twig
{% if dossier|should_display_field('dateReunion') and dossier.dateReunion %}
    <li class="row">
        <div class="left libelle col-md-3">Date réunion</div>
        ...
```

**Impact** : Ce bug empêchait l'affichage de la date de réunion pour les natures 31 et 32 ❌  
**Résolution** : Correction de la condition ✅
